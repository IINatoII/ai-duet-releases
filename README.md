# AI Duet

Claude와 GPT를 연결해 답변 작성·교차 검토·역할 분담을 수행하는 Windows 앱입니다.

## 설치

[최신 설치 파일 받기](https://github.com/IINatoII/ai-duet-releases/releases/latest)

Windows 64비트용 `AI-Duet-버전-setup.exe`를 실행하세요.

## 업데이트

1.6.1 이상에서는 프로그램 설정 → 프로그램 업데이트에서 **새 버전 확인 → 업데이트 다운로드 → 재시작하여 업데이트**를 누르면 됩니다. 이전 1.6.0 사용자는 최초 한 번 새 설치 파일을 실행해야 합니다.

진행 중인 AI 작업을 마치거나 취소한 뒤 업데이트하세요. 채팅과 설정은 유지됩니다.

이 저장소에는 설치 파일과 업데이트 정보만 배포합니다. 개발 소스는 별도 비공개 저장소에서 관리합니다.
